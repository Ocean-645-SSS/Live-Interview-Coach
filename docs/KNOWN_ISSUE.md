# 发布边界与已知限制

## 数据库迁移

Interview Coach 使用 PostgreSQL 与 Alembic。生产发布必须显式执行 `alembic upgrade head` 并记录迁移版本，不能假定空数据库会自动获得业务表结构。

## 外部服务依赖

实时面试依赖 LiveKit、火山引擎 STT、DashScope TTS/LLM、RAG LLM 与 Embedding 服务。自动化测试不能替代目标地区网络、供应商配额、模型版本和真实浏览器音频链路验收。

## 公司情报

`INTERVIEW_INTELLIGENCE_ENABLED` 默认关闭。启用外部公司面经来源前，应确认来源许可、访问频率、隐私与内容时效；该能力不可用时仍可使用候选人资料、岗位资料和题库完成面试。

## 生产 LiveKit

本地 Compose 凭据仅用于开发。生产必须更换高强度密钥、使用可信 `wss://` 入口，并验证 `7881/TCP`、`7882/UDP` 或托管 LiveKit 对应媒体通道。

## 发布验收

至少使用生产同类凭据完成一次“创建资料库 → 生成计划 → 加入房间 → 回答与追问 → 生成报告”的完整链路，并记录模型耗时、检索命中、断线重连和错误日志。
